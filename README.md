# 🔧 FreeTool.site — Free Online Developer Tools

A collection of 8 free online developer and productivity tools. Fast, privacy-friendly, no signup required.

**Live Site**: https://plan-a-tools-website.vercel.app  
**GitHub**: https://github.com/lihualih/freetool-site

---

## 🛠️ Tools Included

| Tool | Description |
|------|-------------|
| **JSON Formatter** | Beautify, minify, and validate JSON data |
| **Word Counter** | Count words, characters, sentences, paragraphs with text transforms |
| **Password Generator** | Generate cryptographically secure passwords with customizable options |
| **Color Converter** | Convert between HEX, RGB, HSL with visual color picker |
| **Base64 Encoder/Decoder** | Encode and decode Base64 strings (UTF-8 supported) |
| **URL Encoder/Decoder** | Encode and decode URLs with component breakdown |
| **Unix Timestamp Converter** | Convert between timestamps and human-readable dates (live clock) |
| **QR Code Generator** | Generate QR codes from text/URLs with customizable size and colors |

## ⚡ Tech Stack

- **HTML5 / CSS3 / Vanilla JavaScript** — Zero dependencies, instant loading
- **Client-side processing** — All data stays in your browser, nothing uploaded
- **Responsive design** — Works on desktop, tablet, and mobile
- **Dark mode** — Automatic detection + manual toggle
- **SEO optimized** — Meta tags, structured data (JSON-LD), sitemap.xml

## 🚀 How to Use

1. Visit the site
2. Click any tool card
3. Paste/type your input
4. Get instant results
5. Copy or download the output

No signup, no API keys, no data collection.

## 📦 Deployment

### Vercel (Recommended — Free)
```bash
npm i -g vercel
vercel login
vercel --prod
```

### Cloudflare Pages
1. Push to GitHub
2. Cloudflare Pages → Connect to Git → Deploy
3. Build output: `/` (root)
