# FreeTool.site - 免费在线工具集合

## 项目概述
一个免费在线工具网站，包含多种实用工具，通过 Google AdSense 广告和联盟营销获取被动收入。

## 包含工具
1. JSON 格式化/验证器
2. 文字字数统计 & 大小写转换
3. 密码生成器
4. 颜色格式转换器（HEX/RGB/HSL）
5. Base64 编解码
6. URL 编解码
7. 时间戳转换器
8. 二维码生成器

## 技术栈
- 纯 HTML/CSS/JavaScript（零依赖，极速加载）
- 响应式设计（移动端友好）
- SEO 优化（每个工具独立页面）

## 部署方式
- **推荐**: Cloudflare Pages（免费，全球CDN）
- **备选**: Vercel / GitHub Pages / Netlify

## 收益模式
1. Google AdSense 广告
2. 联盟营销（推荐相关工具/服务）
3. Buy Me a Coffee / Ko-fi 捐赠按钮
